# 014-02 历史文档简体中文规范化子任务

状态：待办

父任务：

- `tasks/in-progress/011-mvp-service-onboarding-parent.md`

上游来源：

- `AGENTS.md`
- `docs/reports/014-documentation-organization-2026-06-03.md`

## 背景

`AGENTS.md` 要求所有回复、文档、注释和代码解释使用简体中文。当前历史迁移文档和部分架构文档仍保留英文内容，需要在不改变技术含义的前提下逐步规范化。

## 目标

- 将历史英文文档逐步改写为简体中文。
- 保留 API、类名、变量名、队列名、Deployment 名称等专有名词英文。
- 不改变既有迁移结论和验证结果。

## 非目标

- 不修改服务代码。
- 不重写架构决策。
- 不改变任务状态。

## 输入

```text
docs/architecture
docs/migrations
docs/k8s
```

## 输出

- 简体中文版本的历史文档。
- 必要时补充术语表或说明。

## 影响范围

```text
docs
```

## 风险

- 翻译过程中可能误改专有名词或技术边界。
- 历史验证结果不得被翻译成新的已验证结论。

## 验收标准

- 文档主体为简体中文。
- 专有名词保留英文。
- 不引入新的状态断言。

## 测试边界

本任务为文档规范化，验证方式为人工审阅和关键词检查。
