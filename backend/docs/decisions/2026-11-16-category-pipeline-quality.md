# 分类清洗、增强与聚合质量改造

## 目标与范围

修复 2026-11-16 生产随机抽样确认的问题：占位权威 ID 导致增强假成功、补齐 JSON 未同步结构化字段、体育场次混聚、短剧人物组合未拆与姓名改字。保留采集、清洗、增强、聚合四服务主流程以及现有作品 ID、绑定、收藏和历史引用。

范围包括共享 ID/人物规则、采集/入库入口、规范化、增强结果收集与分类 provider 策略、聚合类别策略及明确占位数据迁移。优先体育和短剧，电影/剧集/动漫/综艺/纪录片保留已有季、版本、类型和身份约束。未知分类保守处理。展示分类不能直接作为跨类别自动合并的授权。

不做全量清洗重置、无审核拆簇或自动 unified 合并；不把同名或共享外部 ID 当作视频真值。无需创建新项目/工作树/备份。

## 契约与实现

- 新增现有 backend/shared 下的轻量 `ircs-content-metadata` 库，仅供真实消费者使用，避免通用 common 变化导致无关模块重建。
- 权威 ID 缺失持久化为 SQL NULL。四种 provider 分别验证格式、规范化；明确占位无效。格式通过不等于 provider 实体已查证。来源分类/来源视频编号中的 0 不适用此规则。
- 人物原字形保留，仅清实体、宽度和空白，拆分明确中文组合并去重、过滤人物占位；检索归一不覆盖原姓名。人物、地区、语言、类型的锁分别生效。
- 增强器在流水线版本及 provider attempt 校验后，按 pipeline→raw 顺序加锁读取当前行；增强 JSON 与聚合使用的结构化投影在同一事务中持久化，再发送索引/聚合工作。原始 JSON 已含补齐，不把差异一概归为清洗丢失。
- 体育不走通用影视搜索；短剧按 TV/完整片名及严格身份匹配使用适合的 provider。无适用 provider/无匹配采用现有终态，不进行无意义重试；不新增前端不认识的状态。
- 体育以具体日期、对阵、赛事及必要轮次/性别确定场次，比分作为可变化属性。补足 yyyyMMdd 等日期与无日期对阵冲突识别。缺证据可以新建独立作品，不能仅以大赛事标题合并。
- 短剧 title+subtitle 构成完整身份，人物角色分别比较；体育与短剧不根据裸数字臆造影视季。电影/动漫既有有意义数字、多语种、续作/季等能力须回归。
- 清理迁移只将明确占位列改 NULL，跳过人工锁，保留原 JSON、合法 ID、绑定及业务引用，不重置任务。已有错误簇另行审核处理。

## 验收与验证

1. `0` 等占位不触发 SUCCESS、不成为候选/锁键身份；合法 ID 与来源编号保留。
2. 成功补齐的人物、地区/语言/类型可被下游结构化读取；字段锁、并发版本与重复/迟到消息不造成覆盖。
3. 覆盖同日不同赛事、yyyyMMdd、无日期对阵、比分变化、性别/轮次、短剧同主不同副标题、中文组合人物、英文姓名、罗予彤/孙乾钊等原字形。
4. 应用测试/Native 构建仅在 GitHub Actions 执行，本地只允许静态及 CI 规划脚本检查。按真实依赖选择受影响镜像，其余复用发布账本中的不可变镜像。
5. 候选占用新业务版本；发布前核对统一版本契约。部署后对原反例与新随机分层样本分别核验，区分新增正确性、历史存量、当前规则检测覆盖和未确认真值。
6. 对现有字段衔接问题采用带输入指纹/锁保护的审核 cohort 回填或规范化，不重复已完成的外部 provider 请求。验证业务引用和服务运行态。

## 发布与回滚

实现完成、CI 和 Native 运行门禁通过后，通过既有 GitOps 发布。应用回滚使用上一不可变镜像；占位转 NULL 不还原为 0。原始 JSON 与合法 ID 不变，保留追溯能力。新分类算法不自动拆改旧绑定，避免回滚时丢失引用。

## 类别覆盖

覆盖仓库定义的全部 12 个稳定类别，另外保留未知类别的保守路径：

| 类别 | 清洗与增强 | 聚合约束 |
|---|---|---|
| 电影 | 续作数字/部不当成季；电影媒体类型优先 | 年份、演职员、版本与续作序号 |
| 剧集 | 显式季与别名，保留原名 | 季及身份版本冲突不得由共享 ID 覆盖 |
| 动漫 | 季与 Part/cour/篇章分开 | OVA/特别篇/剧场版等格式与篇章约束 |
| 短剧 | 完整主副标题、中文组合人物、可选影视权威 | 完整标题与同角色人物；裸数字不推季 |
| 体育 | 来源事件结构化，不发送影视搜索 | 日期、参与方、赛事、性别与轮次；比分变化不换场次 |
| 综艺 | 保留年度和期/篇标记；按 TV 补齐 | 明确年度版本与节目完整标题 |
| 纪录片 | 单片/连续节目不根据展示类别臆断 | 已知季、篇章、格式与完整标题 |
| 新闻 | 保留日期和标题；来源信息增强 | 具体日期与完整标题，缺日期不足以自动合并 |
| 教育 | 保留课程/章节；讲师映射既有演职人员列 | 完整课程章节与讲师证据，缺讲师不凭同名确认 |
| 音乐 | 保留日期、版本；艺人映射既有演职人员列 | 艺人/演出日期以及现场、录音室、翻唱等版本 |
| 成人类别 | 保守保留标题、编号和来源，不用影视补齐碰运气 | 完整标题，不用近似标题自动归并不同资源 |
| 其他 | 保留编号与原始结构，来源信息增强 | 完整标题与现有身份约束，未知不放宽 |

新闻、教育和音乐在 2026-11-16 的生产样本中没有数据，使用独立正反例测试，不虚构生产准确率。source-only 类别无外部命中仍能进入聚合；现有 PERMANENT_FAILURE 在这里表示终态未取得权威补齐，不等同消费者失败。原始身份、人工锁及合法 ID 不清除。

新增受内部 token/scope 保护的只读清洗预览，单次最多 50 个不同 raw UUID，返回当前源版本和 JSON 指纹；不改变状态、不发布任务。审核存量回填时复用真实清洗算法，并以原行指纹保护，不复制另一套清洗规则，也不触发全量 reset。
