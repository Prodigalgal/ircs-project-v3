# 资源站权威增强

资源站写入来源视频后，清洗 worker 发布当前采集版本的权威增强任务。metadata worker 在清洗状态为 `READY` 后登记启用且适用的权威源。聚合等待该版本的权威增强得到最终结论。

| 权威源 | 搜索与详情 | 出站 |
| --- | --- | --- |
| TMDB | 按规范片名或别名搜索。已有 ID 时按作品或季查详情。验证类型、年份和已知 IMDb ID。 | 现有代理池和凭据配额 |
| IMDb | 按片名或别名筛选站内搜索候选，从 title 页面读取核实过的结构化资料。 | 必须使用配置的代理 |
| 豆瓣 | 按片名或别名筛选候选，再检查 subject 页的作品标识、年份、季和 IMDb 对应关系。 | 必须使用配置的代理 |
| 烂番茄 | 保留可选的站内搜索补充与榜单读取。 | 必须使用配置的代理 |

IMDb 或豆瓣的详情访问受限时，唯一且验证通过的候选可补充其已知字段。确认不到可靠匹配时保留来源资料。体育赛事等不适用影视权威源的内容由增强阶段记录结果，再交给聚合。网络错误、限流和临时故障使用现有队列限次重试。重试期间不会提交该版本的聚合任务。

代理请求复用集群公共出站代理及其冷却和重试路径。代理不可用时请求失败并按原有策略重试。

公开网页请求使用浏览器的页面导航 `Accept`，结构化搜索请求使用 JSON `Accept`。两类请求使用项目默认的浏览器 `User-Agent` 和中文优先的语言偏好，可沿用凭据中已配置的 `User-Agent`。

生产在 metadata worker 启用 `APP_METADATA_TMDB_ENABLED`、`APP_METADATA_IMDB_ENABLED` 和 `APP_METADATA_DOUBAN_ENABLED`。生产定时采集计划独立于这些开关。
